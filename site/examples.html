Examples

All examples live in the examples/ directory. To use one, copy it to project.cue and update export.cue's _modules map.

Minimal — Single Executable

package build

app: #Module & {
    kind: "exe"
    root: "src/main.zig"
}

Produces one binary at zig-out/bin/app.

Multi-Library — Shared + Static + Exe

package build

math: #Module & {
    kind: "shared"
    root: "src/math.zig"
    profile: "release"
}

utils: #Module & {
    kind: "static"
    root: "src/utils.zig"
}

app: #Module & {
    kind:    "exe"
    root:    "src/main.zig"
    deps:    ["math", "utils"]
    profile: "release"
}

math is shared (.dylib/.so), utils is static (.a), app links both.

Microservice — Protocol + Two Services

package build

protocol: #Module & {
    kind:    "static"
    root:    "src/protocol.zig"
    profile: "release"
}

gateway: #Module & {
    kind:    "exe"
    root:    "src/gateway.zig"
    deps:    ["protocol"]
    profile: "release"
}

worker: #Module & {
    kind:    "exe"
    root:    "src/worker.zig"
    deps:    ["protocol"]
    profile: "release"
}

Two binaries (gateway, worker) sharing a protocol library. All optimized for release.
