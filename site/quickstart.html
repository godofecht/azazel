Quickstart

Quickstart (5 minutes)

Declare a module and executable:

package build

core: #Module & {
    kind: "module"
    root: "src/core.zig"
}

app: #Module & {
    kind:    "exe"
    root:    "src/main.zig"
    deps:    ["core"]
    profile: "release"
}

Export them from export.cue:

_modules: {
    "core": core
    "app":  app
}

Then:

python3 azazel check
python3 azazel gen
python3 azazel build
python3 azazel info

Normal Zig build arguments can be forwarded through azazel build.
